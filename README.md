# دفترچه یادداشت با یادآور (React + Vite)

## اجرا
    npm install
    npm run dev

آدرس http://localhost:5173 رو توی Chrome یا Edge باز کن.

## میکروفون
- فقط روی `localhost` یا `https` کار می‌کنه (نه روی http با IP).
- برای تست با گوشی: `npm run dev:https` و آدرس https شبکه‌ی محلی رو باز کن.
- تشخیص گفتار Chrome به اینترنت نیاز داره.
- اگه مجوز بسته شد: آیکن قفل کنار آدرس ← میکروفون ← اجازه ← رفرش.

## ویژگی‌ها
- یادداشت دستی و صوتی (fa-IR) با نمایش زنده‌ی متن
- ذخیره‌ی خودکار با صدا: آخر جمله بگو «اضافه کن» (یا «ثبت کن» / «ذخیره کن»)
- یادآور با زبان طبیعی: «۳ ساعت دیگه»، «ساعت ۱۱ و نیم»، «فردا ساعت ۸»
- آلارم صوتی + اعلان مرورگر + «۵ دقیقه بعد»
- پک‌ها: دسته‌بندی یادداشت‌ها با منوی کشویی بالای صفحه (عمومی، دانشگاه، سایت و...)
  - ساخت با صدا: «یک پک بساز برای کارهای دانشگاه» یا «پک سایت بساز»
  - افزودن با صدا: «خرید کوله برای دانشگاه، اضافه کن» (اگه اسم پک تو جمله نباشه، یادداشت میره تو پک انتخاب‌شده؛ با گزینه‌ی «همه» میره تو «عمومی»)
  - هر پک لیست و نوار پیشرفت زمانی یادآورهای خودش رو داره؛ حذف پک، یادداشت‌هاش رو به «عمومی» منتقل می‌کنه
- فیلتر همه / یادآورها / انجام‌شده، حالت تاریک خودکار

## تست
    npm test

## نکته
یادآورها فقط وقتی کار می‌کنن که تب باز باشه. آلارمی که زنگ زده ولی دیده نشده، با رفرش دوباره نمایش داده می‌شه. تب‌های باز هم‌زمان با هم هماهنگ می‌مونن.

## نسخه‌ی اندروید (Capacitor)

همین کد React داخل یه اپ اندروید قرار می‌گیره. APK با GitHub Actions ساخته می‌شه (Android Studio لازم نیست).

### ساخت APK
1. یه مخزن GitHub بساز و کل این پوشه رو (همراه `.github` و `debug.keystore`) پوش کن.
2. تب **Actions** ← **Build Android APK** ← **Run workflow** (با هر پوش روی `main` هم خودکار اجرا می‌شه).
3. بعد از تموم شدن، پایین صفحه‌ی اجرا، بخش **Artifacts** فایل `notes-app-debug-apk` رو دانلود کن، از زیپ دربیار و `app-debug.apk` رو روی گوشی نصب کن (باید «نصب از منابع ناشناس» رو برای مرورگر/مدیر فایل روشن کنی).
4. اگه مرحله‌ی تست قرمز بود ولی APK ساخته شد، خروجی تست رو برای بررسی بفرست؛ ساخت APK به خاطرش متوقف نمی‌شه.

> `debug.keystore` فقط برای نسخه‌ی تسته. با اون می‌شه APK جدید رو روی قبلی نصب کرد بدون اینکه یادداشت‌ها پاک بشن. برای انتشار روی بازار/مایکت باید یه کلید امضای جدا ساخته بشه.

### قبل از شروع
- `appId` توی `capacitor.config.json` الان `ir.yourname.notes` است؛ قبل از انتشار به شناسه‌ی نهایی عوضش کن (بعد از انتشار قابل تغییر نیست).
- آیکن اپ فعلاً آیکن پیش‌فرض Capacitor است.

### رفتار آلارم (سطح «الف»)
- یادآورها به‌صورت اعلان زمان‌بندی‌شده‌ی سیستم ثبت می‌شن و با اپ بسته و قفل‌صفحه هم میان؛ صدا حدود ۲۰ ثانیه است و تکرار نمی‌شه.
- بار اول، اپ اجازه‌ی اعلان و «آلارم دقیق» رو با یه کارت راهنما می‌خواد.
- روی گوشی‌های شیائومی/سامسونگ/هوآوی بهینه‌سازی باتری رو برای اپ خاموش کن.
- وقتی اپ باز و جلوی چشمه، همون آلارم داخل خود اپ (زنگ تکرارشونده) کار می‌کنه.

### چک‌لیست تست روی گوشی
- یادآور ۲ دقیقه‌ای، بعد قفل کردن صفحه ← صدا و لرزش
- همین تست با حذف اپ از لیست اپ‌های اخیر
- ریبوت بعد از ساخت یادآور
- حالت سایلنت / مزاحم نشوید
- لمس اعلان ← صفحه‌ی آلارم، «باشه» و «۵ دقیقه بعد»
- حذف یا «انجام شد» ← آلارم لغو شه
- میکروفون: «خرید نان، اضافه کن» و «یک پک بساز برای دانشگاه»

### عیب‌یابی روی گوشی
پایین صفحه‌ی اپ (فقط توی نسخه‌ی اندروید) دکمه‌ی «عیب‌یابی آلارم و میکروفون» هست. وضعیت اجازه‌ها، تعداد آلارم‌های ثبت‌شده و آخرین خطاها رو نشون می‌ده. دکمه‌ی «آلارم تست» یه اعلان مستقل ۱۰ ثانیه دیگه ثبت می‌کنه؛ بعد از زدنش برنامه رو ببند یا صفحه رو قفل کن. اگه اعلان تست هم نیومد، مشکل از اجازه‌ها یا تنظیمات گوشیه، نه منطق یادداشت‌ها. «کپی گزارش» متن رو برای ارسال کپی می‌کنه.
